# Network Traffic Analysis

## Overview

This project documents practical network traffic analysis and security investigation using Wireshark.

The goal is to examine captured network traffic, identify normal network behaviour, investigate potentially suspicious activity, and document security findings.

## Objectives

- Analyse network traffic using Wireshark
- Understand TCP/IP communications
- Analyse DNS requests and responses
- Examine HTTP and HTTPS traffic
- Identify suspicious network activity
- Investigate IP addresses and network connections
- Document findings and security recommendations

## Tools Used

- Wireshark
- TCP/IP
- DNS
- HTTP/HTTPS
- Kali Linux

## Methodology

1. Capture or obtain authorised network traffic for analysis.
2. Identify communicating hosts and protocols.
3. Analyse DNS queries and responses.
4. Examine TCP connections and packet behaviour.
5. Investigate unusual or suspicious traffic.
6. Document findings.
7. Provide recommended security controls.

## Ethical Considerations

All analysis in this project is performed in an authorised lab environment or against traffic for which permission has been obtained.
